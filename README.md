# Net-Lab

Simulador de red didáctico y liviano, al estilo Packet Tracer pero mucho más simple, para alumnado de 4.º de ESO y Bachillerato. Se monta un laboratorio en el navegador: router, switch, portátiles, sobremesas y móviles conectados por cable o WiFi, con direcciones IP y MAC visibles, diagnóstico de por qué un equipo no llega a Internet y una animación del recorrido de un paquete.

Aplicación web estática (React + TypeScript + Vite), pensada para publicarse en GitHub Pages. Interfaz en español; código y tests en inglés.
